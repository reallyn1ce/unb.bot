# Economy Bot

Discord-бот с полноценной экономикой для серверов: у каждого сервера свой баланс, своя инфляция, свой Центральный банк и свой государственный бюджет. Включает казино, фондовую биржу, бизнесы и кредиты.

## Функционал

- 🏦 **Центральный банк и резерв** — эмиссия (`!print-money`) и сжигание денег (`!burn-money`); все заработки выплачиваются из резерва ЦБ, налоги уходят в госбюджет
- 🏛️ **Государственный бюджет** — пополняется подоходным налогом, налогом на бизнес и другими сборами
- 📉 **Налоги и инфляция** — инфляция считается по чистой эмиссии за 24 часа и влияет на доход бизнесов (коэффициент настраивается пресетом)
- 💰 **Экономика игрока** — баланс (наличные + банк), переводы, `!work`, `!crime`, `!slut`, `!rob`, вклады и снятие, топ игроков
- 🏢 **Бизнесы** — покупка, улучшение уровней, почасовой доход
- 💳 **Кредиты** — выдача и погашение с ограничением по сроку и штрафом за просрочку
- 🎰 **Казино** — слоты, блэкджек, русская рулетка (соло и с друзьями), статистика игрока
- 📈 **Биржа** — IPO собственных компаний, покупка и продажа акций, графики, список акций
- 📊 **Статистика и графики** — сводка `!economy`, графики денежной массы по запросу (`!graphs`) и автоматически раз в сутки
- ⚙️ **Настройки** — панель `/settings` для администраторов (пресеты, кулдауны и прочие значения вручную, включение модулей, кастомные тексты)
- 🌐 **Health-check** — HTTP-эндпоинты `/` и `/health` для хостингов

Команды, которые есть и в префиксном (`!`), и в слеш-виде, помечены ниже как «`!` и `/`». Админские команды `!print-money`, `!burn-money`, `!set-chart-channel`, `!graphs` — только префиксные.

## Стек технологий

- Python 3
- [discord.py](https://github.com/Rapptz/discord.py) — Discord API
- MongoDB (Atlas) + [Motor](https://motor.readthedocs.io/) / PyMongo — база данных
- aiohttp — HTTP-сервер health-check
- matplotlib — построение графиков

## Запуск

```bash
python bot.py
```

При старте бот проверяет обязательные переменные (`DISCORD_TOKEN`, `MONGO_USER`, `MONGO_PASSWORD`), подключается к MongoDB, создаёт индексы и документы ЦБ и бюджета для всех серверов и синхронизирует слеш-команды. Статус активности (Activity/Presence) бот не устанавливает.

## Автоматические графики

`!set-chart-channel [#канал]` (администратор) задаёт канал, в который раз в сутки в 18:00 UTC бот присылает графики денежной массы (24 часа и вся история). Без настроенного канала автопубликации нет; график по запросу доступен через `!graphs`. Снапшоты денежной массы для графиков бот делает каждые 5 минут независимо от канала.

## Discord Intents

Бот запрашивает только `guilds`, `guild_messages` и `message_content` (нужен для префиксных команд `!`). **Server Members Intent не нужен** — имена участников подгружаются через `fetch_member`. Следствие: в префиксных командах игрока лучше указывать упоминанием (`@user`); поиск по имени или ID без Members Intent может не работать (слеш-команды не затронуты).

## Транзакции

Все денежные операции выполняются в транзакциях MongoDB через `EconomyBot.run_tx`. Временные ошибки (`TransientTransactionError`, например write-conflict на документе резерва ЦБ) и неизвестный результат коммита обрабатываются автоматически: транзакция перезапускается (до 5 попыток с короткой паузой). Бизнес-ошибки (`EconomyError`: не хватает средств, кулдаун и т.д.) откатывают транзакцию без повторов.

## Проверка БД

Два чтения-fallback для старых документов настроек оставлены намеренно — миграция их никогда не переписывала. Если перед их удалением нужно убедиться, что они не нужны, выполните в `mongosh`:

```js
// 1) документы со старыми top-level кулдаунами (вместо eco.cooldown_*)
db.guild_settings.countDocuments({ $or: [
  { cooldown_work: { $exists: true } }, { cooldown_crime: { $exists: true } },
  { cooldown_slut: { $exists: true } }, { cooldown_rob: { $exists: true } } ] })

// 2) документы с пресетом, но без eco.inflation_multiplier
db.guild_settings.countDocuments({ "eco.preset": { $exists: true },
                                    "eco.inflation_multiplier": { $exists: false } })

// 3) нет ли старого уникального индекса только по user_id (мешает мультисерверности)
db.users.getIndexes(); db.businesses.getIndexes(); db.casino_stats.getIndexes()
```

Если оба счётчика равны `0`, а в индексах нет уникального ключа `{ user_id: 1 }` без `guild_id`, fallback-чтение в `EconomyBot.get_settings` можно удалить.

## Обновление с версии с ИИ, `!daily` и отчётами (8.0.0)

Удалены: ИИ (Groq/OpenAI-совместимый API, кнопки в `/settings`, переменные `AI_*`), ежедневные экономические отчёты и `!set-report-channel`, команды `!daily`, `!cb`/`/cb` и `!help`/`/help`, а также установка статуса активности. Модуль «Ежедневный бонус» и настройки `daily_min`, `daily_max`, `cooldown_daily` убраны из `/settings` и пресетов.

Данные в БД бот **не удаляет и не мигрирует**: старые поля (`ai_enabled`, `report_channel_id`, `modules.daily`, `eco.daily_*`, `eco.cooldown_daily`, `users.last_daily`) остаются в документах и просто не читаются; записи журнала транзакций за прошлые `!daily` сохраняются. Автопубликация графиков продолжает работать с уже заданным `chart_channel_id`; поле `last_automation_date` сохранено, поэтому в день обновления графики не продублируются. Если хотите почистить неиспользуемые поля вручную (необязательно):

```js
db.guild_settings.updateMany({}, { $unset: { ai_enabled: "", report_channel_id: "",
  "modules.daily": "", "eco.daily_min": "", "eco.daily_max": "", "eco.cooldown_daily": "",
  cooldown_daily: "" } })
db.users.updateMany({}, { $unset: { last_daily: "" } })
```
